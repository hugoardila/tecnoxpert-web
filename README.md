# TecnoXpert Web

Sitio principal corporativo de TecnoXpert, con páginas de servicios, portafolio, contacto, cotizaciones y flujos de pago.

## Áreas principales

- Inicio, servicios y portafolio.
- Formularios de contacto y solicitudes.
- Cotizaciones y aceptación de propuestas.
- Selección de métodos de pago.
- Webhooks y retornos de pasarelas.
- Contenido legal, robots y sitemap.
- Activos CSS, JavaScript e imágenes de marca.

## Tecnologías

- PHP 8.x y Apache.
- Integraciones de correo y pagos mediante endpoints.
- HTML, CSS y JavaScript.

## Configuración

Las rutas privadas, correo, administración y pasarelas deben configurarse fuera del repositorio. El directorio privado no debe estar dentro del document root.

## Seguridad

Usa HTTPS, valida CSRF y firmas de webhook, limita el panel administrativo y no almacenes claves, comprobantes ni datos de clientes en Git.
